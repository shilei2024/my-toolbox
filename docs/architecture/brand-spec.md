# Mavis Gallery Brand Specification

## Asset source

- Primary mark: `public/brand/mavis-mark.svg`
- Provenance: copied without visual modification from the existing Mavis Toolbox asset at `../../static/img/favicon.svg`.
- Do not redraw, recolor, stretch, or place the mark on a low-contrast background.

## Visual tokens

- Brand blue: `#0d6efd`; active/hover blue: `#0759d6`.
- Brand amber: `#ffc107`, used only as a small status accent.
- Canvas: `#f6f9fc`; primary surface: `#ffffff`.
- Primary ink: `#152438`; secondary ink: `#65758b`.
- Image radius: `4px`; controls: `12px`; overlays: `20px`.
- UI font: Noto Sans SC with system fallbacks.
- Editorial/artwork title font: Noto Serif SC with Songti fallback.
- Motion: 160–240ms; all essential interactions respect `prefers-reduced-motion`.

## Product character

The Gallery should feel like a quiet creative archive: artwork leads, interface recedes. Avoid purple-pink AI gradients, fabricated engagement metrics, decorative logo variants, and overly rounded image cards.

## v0 placeholder policy

Every non-production asset or value must be visibly labeled as pending. Placeholder cards describe only their required aspect ratio and never imply a real artwork, creator, model, prompt, date, or engagement count.
