# 永久工程原则与 Golden Rule

状态：生效

适用范围：MindfulPenPal AI Toolbox Platform 全仓库、全部未来模块和生产发布。

自动化开发者必须执行的仓库级规则位于 [`/AGENTS.md`](../../AGENTS.md)。本文档是供产品、开发、评审和运维共同阅读的权威说明。

## Golden Rule

任何功能进入实现前，必须回答：

1. 是否会影响已经在线的生产网站？
2. 该能力是否可以被未来 AI 模块复用？
3. 是否存在更简单、运维成本更低的方案？
4. 零 DevOps 经验的操作者能否部署和维护？
5. 是否符合平台长期架构？

任意答案为“否”，必须在写代码前重新设计。若能力确实应该保持模块专用，应明确其业务边界和不下沉为共享能力的理由。

## 决策优先级

```text
生产安全与数据完整性
→ 安全与合规
→ 长期可维护性
→ 复用性与可扩展性
→ 稳定性与性能
→ 运维成本
→ 实现速度
```

实现速度不能凌驾于架构质量，但也不以“长期架构”为理由过度设计。应选择满足真实生产要求的最低复杂度方案。

## 实现前检查

### 需求与架构

- 明确真实目标、范围、验收标准和授权边界。
- 检查现有模块、数据库、部署、API、Provider 契约、文档和路线图。
- 未经明确批准，不改变已确认的核心架构。

### 风险

- 生产影响和兼容性
- 数据库迁移与数据恢复
- 安全、隐私和凭据边界
- 成本、性能和容量
- 回滚与未来维护

### 实施计划

计划至少说明目标、范围、受影响文件、新文件、数据库/API 变化、测试、发布顺序和回滚。小改动可以使用简短计划，不能跳过 Golden Rule。

## 平台约束

- MindfulPenPal 是 AI Toolbox Platform，图片只是第一个模块。
- 只允许一个统一管理后台。
- AI、支付和存储都必须通过 Provider 抽象；业务层不得绑定具体供应商。
- 认证、积分、支付、Provider Registry、存储、队列、任务、通知、日志、监控和配置优先建设为共享能力。
- PostgreSQL 保存业务事实；Redis/BullMQ 只承担调度和短期运行状态。
- 腾讯云 COS 是当前默认永久存储；ComfyUI 和远端 Provider URL 不是永久资产地址。
- 中国大陆用户支付优先微信支付、支付宝；Stripe 只作为国际回退。

## 发布与完成标准

生产变更只能在评审、自动化测试、预览/预生产验证、备份恢复和回滚准备完成后发布。完成条件包括代码、类型/构建、单元与集成测试、安全、性能、成本、监控、文档和回滚相互一致。

重要变更必须同步更新集中式 `/docs`：设计、ADR、API、部署、配置、排障、回滚、时序、成本、安全、未来扩展和 changelog 按实际影响维护。
