# ADR-0041：微信轻量录入复用平台身份及报销事务

2026-10-28；代码候选，未生产启用；承接 [ADR-0040](0040-invoice-retention-and-accounting.md)。

## Why

用户需要手机随手保存发票，电脑核对和批量打印。采用原生小程序和现有 Flask/PostgreSQL，同一个网站用户和报销 owner，不另建后台、账户、数据库、云开发或队列。个人主体可选类目、备案及审核以微信后台实际结果为准。

## Decision

外部身份映射、一次性绑定挑战、可撤销移动会话和账户审计放 auth 域；报销原件、票据、上传幂等凭证和用量在同一数据库事务提交。网站二次密码确认生成十分钟绑定码；服务端用 wx.login 临时 code 换取身份后消费，令牌只存 SHA-256 摘要，七天过期。User 行锁串行化绑定/解绑与同用户上传；数据库唯一约束处理跨用户身份竞争。锁后重查过期、会话和用量，避免等锁越过安全边界。

移动接口只接受 Bearer，不接受 Cookie；手机凭据不能登录主站其他模块。网站绑定入口仍受登录、fresh session、密码和 CSRF 保护。身份解绑立即撤销全部移动会话；转绑要求先解绑，不自动认领匿名历史数据。审计不存绑定码、令牌或微信原始响应。

原件20MB、PDF/PNG/JPG扩展名及内容签名校验，内容摘要按 owner 去重。历史摘要NULL允许兼容重复原件，访问时逐步填充，不全表重算。手机普通发票默认待确认，其他类型仅留存打印；金额和公里数均不改变。来源图片由系统压缩选择时不声称保留了相机未压缩原图。

## Alternatives Considered

- H5嵌入：未解决微信原生文件选择/身份体验，仍需鉴权，个人主体能力不能预设。
- 云开发/独立数据库：引入同步、权限与备份两套事实源，拒绝。
- 同步OCR/任务队列：此次不识别金额，无需额外常驻资源。
- 直接COS上传：会绕过当前原件事务边界；MVP先复用BLOB，后续独立存储适配方案。

## Future Impact / Performance / Cost

外部身份与撤销会话可供未来移动模块复用，票据意图和幂等仍属报销域。每次认证只查询摘要/身份/用户；上传同用户串行，客户端顺序上传，足够个人低频录入。无新增云资源，主要增量为原件容量和备份体积，20MB及既有用量限制降低失控风险。BLOB仍是持久原件，桌面上传另有磁盘缓存，手机无需预提交落盘。维护中观察数据库大小和恢复时间，再决定存储演进。

## Security

AppSecret/session_key不进客户端；不记录含密钥的微信URL或异常。openid只由服务器换取，客户端owner_id拒绝。移动蓝图独立CSRF豁免且拒绝Cookie；所有敏感响应no-store。文件内容签名并非恶意文件扫描；原件需鉴权，浏览器预览延续既有隔离，未新增公开URL。无电话/位置/联系人采集，隐私授权拒绝时不能选择文件。真机验证仍必需。

## Rollback Plan

先关闭WECHAT_MINI_ENABLED并重启主站，手机接口404，网站保留使用。新增f5迁移只加表/列/约束，历史原件摘要NULL，不改金额。保留表、票据和绑定审计，不在生产downgrade。回到兼容e4应用前关闭开关，确认留存口径仍被支持；不能回到忽略ADR-0040口径的旧版恢复导出。备份在隔离库验证后才可恢复，恢复会影响备份之后写入，须明确停写窗口。
