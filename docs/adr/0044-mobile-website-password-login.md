# ADR-0044：小程序复用网站密码及隔离审核账号

日期：2026-10-31。状态：已接受设计，候选待生产验证。

Why：微信审核人员不能使用短期一次性绑定码作为稳定的多人员登录方式；用户明确选择增加正常网站账号密码登录。新用户体验同时删除上传前重复的“本次录入”卡片。

决定：所有已授权网站用户均可使用邮箱/密码，不设审核后门。复用User、工具grant、ExternalIdentity和MobileSession；website_password身份摘要包括用户ID与当前密码hash，24小时Bearer、独立撤销、修改密码立即使旧密码会话失效。微信登录与绑定保持独立；不签网站Cookie，不在小程序保存密码。

接口严格4KB有界JSON、字段长度、通用失败、假hash、IP和规范邮箱摘要限流。沿用现有Flask-Limiter存储；memory://时限制属于每worker且重启清零，不能称为跨worker全局限制。已有Redis存储可由独立运维变更配置，不因本功能增加服务/依赖。

审核材料仅创建独立普通free用户和报销grant、合成组织/客户/周期/PDF原件/派车，无真实组织关系或管理员角色。每日40次正常配额，普通登录与业务接口。随机凭据保存在服务器root私有文件，创建单事务；pending记录支持提交后文件写失败恢复，重跑不重置已有密码/资料。不改变审核与正式用户的产品行为。

上传前不再重复选择周期、客户、月份等。首页选择当前期，原件先review暂存；办事处采用既有首项默认并在核对页展示可改，发生月留空不猜，客户/用途/发生月在核对页确认。API兼容空发生月、非空严格校验。快照、幂等重试、费用与公里规则不变。

Alternatives Considered：长期绑定码和审核通用码会扩大身份边界；隐藏审核模式会产生不同业务行为；新账户系统/数据库或队列没有必要。正常密码入口可复用现有身份模型、最低成本。

Future Impact：不新增schema/provider依赖；未来账户模块可以复用身份与会话约定。审核账号只是普通业务用户，可按正常用户管理禁用、改密或撤权，不自动清库/切换产品行为。

Performance / Cost：每次登录一次已有密码hash检查，受限流和用户行锁约束。无新服务、模型调用或迁移；演示PDF/样本仅新账号持有，持续上传仍按正常配额。

Security：密码、session token和AppSecret不进日志/代码；token仅摘要入库。每次请求重查密码版本、账号状态、grant和owner。凭据文件0600、目录0700，备份文件本身敏感；审核后台与本人终端私下填写，不能贴聊天。

Rollback Plan：退回c74de7e及0.10.2客户端，保持f5、新账号、原件和资料；旧auth拒绝password provider。新客户端空发生月需要新后端，回旧代码时需同时回客户端，或暂由网站处理。绝不回库覆盖新写入或downgrade。
