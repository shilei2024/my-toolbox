# ADR-0043：移动票据缺失金额拆分

日期：2026-10-31。状态：候选，待发布验收。

Why：高铁票等只有票价时，移动确认将缺失金额当0而拒绝正常录入。通用金额校验仍必要。

决定：领域纯函数只补空白组件，Decimal保持分精度。两个已知数相加/减；只有总额提供金额等于总额、税额暂记0的可编辑建议，明确不作税务判断，显式确认后写现有记录。已有三个数不一致不修正。草稿缓存读时兼容，确认支持旧客户端空白。原生页加说明和主动补齐按钮。

Alternatives Considered：删除合计校验会允许错误账目；固定高铁税率会产生未证实税额；每次重新OCR会重复花费且不解决原票未单列问题；新表/服务对本修复无益。

Future Impact：纯函数可供报销其他入口复用，暂不改变网站既有保存契约；税务状态扩展应另做明确业务设计，不把暂记0视作免税。

Performance / Cost：每票常数次Decimal计算，无新依赖/存储/模型调用。

Security：保留Bearer/owner/快照/明确确认和审计，不触及登录配置或真实历史数据。

Rollback Plan：代码退回1c1f192，保持f5及新增记录；不要恢复旧数据库覆盖新数据。旧代码拒绝仍空白的确认，用户可按原票手工补齐后保存。客户端可暂用0.10.1，后端修复兼容其空白请求。
