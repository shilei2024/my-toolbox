## 已确认方案（2026-11-14）

1. 以现有 users.id 作为 account_id，扩展现有身份表，沿用 Flask 认证权威，不新增独立认证平台。
2. 小程序可独立注册，用户已明确注册即可使用发票助手；新微信账号仅自动获得 reimbursement grant，其他权限保持隔离。
3. 有业务数据的双账号首版阻止自动合并，提供人工处理入口；安全证明成立的空来源账号可关联。不开“强制覆盖”。
4. 复用 SMTP，补可信邮箱验证、自助找回及全端会话撤销；实际发信供应商部署前验证可达性/额度，不购买付费服务。
5. 已获准进入 Phase 1；真实数据迁移仍须有恢复库和备份对账证据。
