# 小程序与网站录入字段对齐（2026-10-30）

用户要求录入完全一致，优先补齐客户及所有网站发票弹窗字段与关联应酬/出差信息。基础0.10.0 PR已合入main，但不能据此声称本轮补齐已上线。

Golden Rule：会影响生产移动API和表单，独立分支/测试/审查/恢复库后发布；复用网站客户目录、组织权限、创建服务、客户等级、保存及关联明细，不另建客户库；无迁移/依赖/新资源，最低运维成本；沿用现有后端先行/人工命令；符合单体及同一事实源。

范围与验收：bootstrap提供与网站同一客户目录、等级、创建权限、费用类别export_key及产品线code；选择客户自动带等级且不可伪造，清空客户支持手选等级；按同权限可新增客户。发票表单保留全部现有票面/归属/用途/月/打印/备注字段，增加金额核对状态、产品代码只读，以及应酬日期/类别/地点/客户/参与人/金额/事由/审批和出差日期/地点/客户/费用类型/金额/事由。客户只来自当前组织，关联客户与等级由服务端统一赋值，不能客户端跨组织注入。显式关联明细按快照保存；旧客户端未传新字段保留原数据。分类切换复用网站规则。无schema变化；回滚保留客户及明细，不还原数据库。

测试：同组织目录一致/客户选择与清空/等级来源/新增客户权限/跨组织拒绝/手填关联明细与网站及导出一致/旧客户端保留、实际JS及WXML编译；每个字段均核对网站invoicePayload，原件由现有受控上传/下载处理，状态为网站只读状态。再次恢复库和真机验收前不宣称完成上线。

## 网站字段核对表

| 网站录入项 | 小程序处理 |
| --- | --- |
| 周期、办事处、费用类别、产品线 | 同一目录picker，产品线代码只读自动显示 |
| 号码、日期、开票单位、未税金额、税额、价税合计 | 可编辑；未税/税额计算合计，OCR仅建议 |
| 用途、计入口径、发生月、结算月、金额已核对、选入打印 | 独立编辑；月份可清空，费用仍服务端校验 |
| 关联客户、客户等级、新增客户 | 同组织客户目录，等级自动带出，新增同网站角色权限 |
| 摘要、备注 | 可编辑 |
| 应酬：日期、费用类别、用餐地点、客户、参与人、金额、事由、审批 | 条件显示可编辑，客户来自关联选择 |
| 出差：日期、出差地、客户、费用类型、金额、事由 | 条件显示可编辑，客户来自关联选择 |
| 原件与状态 | 现有受控上传/查看原件，状态只读；不从客户端接收可信原件URL |

差异说明：本轮保证录入信息覆盖；客户模块的客户更多资料管理、网站ZIP提取/分摊/批量打印继续原入口。更换已保存原件的手机操作仍须独立实现，不能把“字段对齐”说成所有网站操作均已复制。网站force联动有手工明细覆盖风险；移动端只跟随未被用户改动的默认字段，保留独立金额/日期/事由，网站问题后续修复。
