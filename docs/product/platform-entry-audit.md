# 平台入口与 Gallery 读取梳理（2026-11-17）

## 范围与设计结论

本轮检查主站公共导航、29 个注册工具的模块入口、统一认证桥接、Gallery 的页面/接口/生成服务会话校验，以及前两轮小程序修改。保留 Flask 主站、Next Gallery、Generation Service 和原生小程序的现有架构，不拆服务，不引入 UI 框架，不迁移数据库。入口、文案属于共享展示层；作品访问保持领域服务授权。成本仅为现有前端重新构建。上线会影响页面导航与错误恢复，须先预览再发布；回退前端版本即可，不操作业务数据。

这是代码及公开接口审计，不等于全部工具已逐页真实业务验收。付费任务、管理员操作、客户/报销实际数据及登录态线上验收仍需授权账号与体验环境，不应删除未经确认的页面。

## Gallery 故障证据及修复

正式 Gallery 子域匿名 `/api/gallery`、`?sort=popular`、`?limit=48` 和 facets 均返回200，公开作品18件。操作员反馈“登录后公开作品失败，退出后正常”。主域请求本次探测返回403，不能据此判定源站错误，也不能把它误当 Gallery 子域故障。

代码确认：Generation 服务在 AUTH_ENFORCE_SESSION 开启时，对所有非匿名请求校验可撤销会话；旧前端/过期身份可令公开 GET 也返回401。当前源码已携带 v2 的 authEpoch/sessionRef，但线上前端版本及真实登录响应未独立核实。应核对是否只部署主站/服务端而未更新 Gallery 前端，不能宣称已确定具体线上提交有误。

修复：仅公开 `/v1/gallery`、facets、详情的 GET 在非匿名401后，用匿名身份最多重试一次；不回退个人作品、收藏、计费、任何写入或403。始终经现有服务端公开审核过滤，不扩大可见范围。映射 authentication_required 为重新登录提示。失败页面提供重试；个人页读取错误不再伪装成空作品。

## 验证、发布与恢复

新增回归覆盖公开读取401回退、匿名最多一次、私人接口/写入/403不回退。前端全量测试、lint、类型检查和构建，主站认证桥接与跳转测试为本轮门禁。

发布按 [Vercel 前端部署](../deployment/vercel-deployment.md) 和 [发布清单](../operations/release-checklist.md) 进行。必须同步部署 Gallery 前端，单独重启 mytoolbox 不会更新 Next 应用。主站导航修改则随主站常规发布；无数据库迁移、新环境变量或基础设施。

体验验收：匿名公开列表、登录后公开列表、详情与筛选均可读取；退出/改密后公开浏览可用，个人资源拒绝旧身份；重新登录后个人作品/收藏/任务正常，错误不显示为空数据；品牌回工具库、画廊到个人空间入口可用。若个人页仍失败，在服务器/托管后台核对前端发布提交、401或5xx状态、会话桥接配置；只报告状态和检查结果，不提交凭据或日志正文。

本轮不宣称已修复全部业务模块的所有页面。后续逐模块真实验收应从报销、客户项目、PDF/图片工具、会员计费依次执行，发现具体错误后保留功能并修正，避免未经验证的大规模删页。

本地结果：Gallery 22项测试、修改文件lint与TypeScript检查通过；主站认证桥接/跳转12项测试通过。Next生产编译、类型检查与24页生成完成；首次构建被依赖安全提示中断，复跑构建完成但仍提示当前Next版本存在已知安全问题，正式发布前须核验公告并完成对应升级。真机/已登录预览及生产上线未执行。
