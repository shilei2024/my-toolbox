# 发票助手小程序视觉统一（2026-10-30）

目标：五个页面使用一致的中文字号、卡片、表单、按钮和状态样式，减轻长表单的阅读负担。参考腾讯官方 [WeUI for 小程序](https://github.com/Tencent/weui-wxss) 的原生控件体验与 [Material typography](https://m3.material.io/styles/typography/overview) 的文字层级原则，视觉样式自行实现。

Golden Rule：生产影响限小程序视图与样式，网站业务/API/数据库不变；共享样式可供后续小程序页面复用，财务页面编排保持模块内；原生WXML/WXSS无需组件库、字体下载或新增云资源；开发者工具直接编译，发布和回滚沿用现有客户端流程；保持平台单体、共享客户目录和服务端业务规则。

计划：集中app.wxss的配色与排版，删除页面重复覆盖；重排首页、录入、核对、派车、账号页面；保留已有事件绑定与全部字段。预计一次中型视觉迭代。无迁移、接口和计费变化。核对事件绑定、JS回归与WXML结构，生成使用合成数据的浏览器视觉预览，检查窄屏和长文本。浏览器预览仅用于布局评估，微信原生picker、switch、键盘与安全区需开发者工具及真机验收。

视觉约定：背景#F3F5F4，正文#182C25，强调#176B50；主标题44rpx，章节标题32rpx，输入值30rpx，标签26rpx，说明24rpx；8rpx间距基准，页面边距32rpx、卡片内边距32rpx、卡片间距24rpx。可点击行至少88rpx，按钮96rpx；金额用清晰数字层级，次要操作用浅色或文字按钮。长字段允许换行，输入标签独立于输入值。无需远程字体或装饰图片。

回滚：回退本次WXML/WXSS及app.json主题颜色即可，无数据回滚。现有客户上传同步后端仍须先部署；视觉改版不能替代后端发布验收。保留当前开发者工具project.config.json的操作者修改。

验证记录：微信开发者工具2.02.2609240随附wcc编译五份WXML、wcsc编译app与五页WXSS均退出0。逐页核对旧事件绑定及data-key字段无遗漏；现有实际客户端JS回归2项通过。浏览器以当前WXML/WXSS和合成数据评估375px、320px，包含长客户名称、核对页底部、派车编辑、登录/未登录状态，无横向溢出。预览模拟原生控件，不能替代Android/iOS键盘、picker、switch和真实网络验收。
