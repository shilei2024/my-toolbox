# 客户项目物料机会分类与 TAM/SAM/SOM 发布手册

## 影响与门禁

本次影响客户项目详情、Excel 导出和 `project_materials`。迁移只新增非空分类列、检查约束和索引；历史物料默认归入“设计中物料”。生产功能开关继续默认关闭，必须先在同版本 PostgreSQL staging 验证。

## 迁移

先备份并验证恢复点，然后执行：

```powershell
$env:FLASK_APP = "app:create_app"
flask db current
flask db upgrade
flask db current
```

升级前预期为 `f7a8b9c0d1e2`，升级后为 `a8b9c0d1e2f3`。审阅 SQL，确认只新增 `opportunity_type`、检查约束和 `(project_id, opportunity_type)` 索引，不删除或改写现有价格、数量和竞品记录。

## 验收

1. 创建项目时年用量只能输入正整数；小数、零和负数被拒绝。
2. 新增三类物料，点击推广型号可打开编辑弹窗并更新分类、型号、数量和价格。
3. 点击竞品型号可打开竞品编辑弹窗，过期版本仍返回 409。
4. 核对单条年度机会金额为年用量 × 单机数量 × 美金单价。
5. 核对 TAM 为三类总和，SAM 为设计中与已匹配总和，SOM 为设计中总和。
6. 缺少数量或美金单价的物料不计入，并显示待补齐提示。
7. Excel 导出包含机会分类和年度机会金额，仍遵守价格权限与行数上限。
8. 在 320px、768px、1280px 验证弹窗、三类分组和市场规模卡片。

## 回滚

关闭客户项目功能开关后回退应用版本；保留新增列和分类数据，不执行生产 downgrade。旧版本忽略新列。若分类导致业务口径争议，可先把物料调整为“设计中物料”，但必须通过正常页面/API 留下审计，不直接改库。
